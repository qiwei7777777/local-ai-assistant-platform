# Roadmap

## Completed

- Local Ollama-backed chat
- Multi-session persistence
- Streaming and non-streaming chat modes
- Stop generation handling
- Model list and model switching
- File upload and parsing
- Knowledge bases and local retrieval
- Explicit memory
- Developer diagnostics
- Python SDK
- Windows startup scripts
- Regression tests and frontend build validation

## Next

1. Add OpenAI-compatible adapter support for Ollama `/v1` and optional remote providers.
2. Add structured-output workflows for extraction and report generation.
3. Add tool-calling workflows for retrieval, memory, and file search.
4. Replace keyword retrieval with embeddings and a vector store.
5. Add conversation export for project-management reports and portfolio demos.
6. Add persisted user settings.
7. Add Docker Compose for cross-platform setup.
